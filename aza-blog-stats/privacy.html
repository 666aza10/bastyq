Privacy Policy

Aza Blog Stats · last updated 31 August 2026

Aza Blog Stats is a private, single-user tool. It reads statistics for the TikTok account owned by its developer and shows them in a private weekly report. It is not a product offered to the public, it has no other users, and it does not publish anything to TikTok.

What data is accessed

Through the TikTok API, and only for the account that has explicitly authorised the app, the following is read:

  • account statistics: follower count, following count, likes count, video count (scope user.info.stats);
  • the list of the account's own public videos and their public metrics (scope video.list);
  • basic profile identifiers supplied by TikTok Login Kit (scope user.info.basic).

What is not accessed

  • No data about any other TikTok user is requested or received.
  • No private messages, no contact lists, no personal data of viewers or followers.
  • Nothing is posted, edited or deleted on TikTok by this app.

How the data is used and stored

The numbers are placed into a private weekly summary delivered to the account owner in a private Telegram chat. Only aggregate counts are kept, so that the next week's report can show the change since the previous one. The data is not sold, shared, published, or used for advertising or profiling.

Access tokens

The authorisation token is stored as an environment variable on the server that generates the report and is never written to logs or shared with third parties.

Retention and deletion

Authorisation can be revoked at any time in TikTok settings, which immediately stops all access. To have the stored counts deleted, contact the address below; they will be erased on request.
