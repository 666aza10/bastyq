What this is

Aza Blog Stats is a private tool built by its developer for personal use. It reads the statistics of the developer's own TikTok account and includes them in a private weekly summary alongside numbers from other platforms. It is not sold, not distributed, and has no users other than its developer.

Use of the TikTok API

The app accesses the TikTok API only for an account that has explicitly granted authorisation, and only to read statistics. It does not post, edit or delete content, does not access other users' data, and does not attempt to circumvent any platform restriction. Use of the API is subject to the TikTok Developer Terms of Service, which take precedence over this document.

No warranty

The tool is provided as is, with no warranty of any kind. Numbers are read from the platform and may be incomplete or delayed. Nothing here should be relied upon as an authoritative record.

Changes and termination

The developer may change or shut down the tool at any time. Authorisation can be revoked at any time in TikTok settings, which immediately ends all access.
